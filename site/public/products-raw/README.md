# Banco de imagens brutas dos produtos

Cada pasta aqui corresponde a um modelo do catálogo (SKU + nome). Suba aqui
as fotos originais que você encontrar (do fabricante, de lojas revendedoras,
ou tiradas por vocês) — sem nenhuma edição, do jeito que baixar.

Sugestão de ângulos por modelo (nem todos precisam existir, mas quanto mais
completo, melhor):
- Frente 3/4
- Traseira 3/4
- Lateral
- Detalhe (interior, motor, mecanismo aberto)
- Foto da caixa

Depois de subidas aqui, essas fotos passam por um processamento (remoção de
fundo + composição na cena padrão do Studio 18 — mesa de madeira, poltronas
de couro, estante ao fundo) antes de irem para o site de verdade em
`site/public/products/`. Esta pasta (`products-raw/`) é só a área de
rascunho/upload, as imagens daqui não aparecem no site.
