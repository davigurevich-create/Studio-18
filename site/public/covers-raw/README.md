# Banco de imagens brutas das CAPAS dos produtos

Cada pasta aqui corresponde a um modelo do catálogo que precisa de uma capa
nova (`image_url`) porque a atual está em resolução baixa. Suba aqui **1
foto** do produto no mesmo ângulo/pose da capa que já existe no site (uma
vista de 3/4 mostrando bem o carro/moto), na melhor resolução que você
encontrar. Se tiver mais de uma opção de foto boa pro mesmo ângulo, pode
subir mais de uma — eu escolho a melhor ou pergunto qual prefere.

Sem edição necessária: se a foto tiver banner de texto, seta, linha de
dimensão etc. (comum em fotos de anúncio), eu recorto isso antes de gerar a
capa final. Só evite prints de tela ou imagens muito pequenas (abaixo de uns
500px) se puder.

Depois de subidas aqui, essas fotos passam pelo mesmo processamento das
galerias (composição na cena padrão do Studio 18 — mesa de madeira,
poltronas de couro, estante ao fundo) antes de irem para
`site/public/products/S18-0XX.jpg`. Esta pasta é só a área de
rascunho/upload, as imagens daqui não aparecem no site.
